# gh-noauth

A version of [`gh`](https://github.com/cli/cli) that relies on `GH_TOKEN` or `GITHUB_TOKEN` for authentication, as `gh auth` and its subcommands are disabled.

![screenshot of gh pr status](https://user-images.githubusercontent.com/98482/84171218-327e7a80-aa40-11ea-8cd1-5177fc2d0e72.png)

## Build

```shell
nix build
```
